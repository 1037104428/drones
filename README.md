# battlefield-sim

Rust simulator of a circular battlefield swept by a 2×6 formation of expendable FPV drones. Twenty static targets are placed uniformly in the disk. Targeting algorithms are pluggable. Scores are deterministic `compute_ops` and mean target survival (survivors are censored at \(T_{\mathrm{end}}\)).

**Repository:** <https://github.com/1037104428/drones>

- Paper (Chinese): [`paper/fpv_emergent.pdf`](paper/fpv_emergent.pdf)
- Paper (English): [`paper/fpv_emergent_en.pdf`](paper/fpv_emergent_en.pdf)
- Chinese README: [`README.zh.md`](README.zh.md)

## Build and test

```bash
git clone https://github.com/1037104428/drones.git
cd drones
cargo test
```

## Reproduce the paper experiment

The Transformer is trained with **per-tick REINFORCE** (no imitation): after every simulation step the 12 drones are updated in one parallel batch. The team reward is the increment of mean survival, \(-n_{\mathrm{alive}}\Delta t/N + n_{\mathrm{kills}}(T_{\mathrm{end}}-t)/N\). Compute time is **not** in the loss.

```bash
# --release is required; debug Transformer forwards are too slow
cargo run --release -- experiment --train-rounds 200 --eval-rounds 30 --seed 20260823
# Gaussian swarm ingress from the south (σx=70 m, σy=30 m):
cargo run --release -- experiment --ingress gaussian --train-rounds 200 --eval-rounds 30 --seed 20260823
# Same-tick lock radio (120 m); at D_tgt=50 m outcomes match no-radio:
cargo run --release -- experiment --comms-range 120 --train-rounds 200 --eval-rounds 30 --seed 20260823
```

This evaluates three algorithms on the same 30 seeds:

| Algorithm | Role |
|-----------|------|
| `nearest_in_range` | Greedy: nearest in-range unlocked target |
| `greedy_no_comms` | Greedy with no friend info and no lock awareness |
| `closer_than_friend` | Fire only if nearest target is strictly closer than nearest visible teammate |
| `transformer` | Onboard-AI analogue, trained by per-tick RL |

Artifacts:

| Path | Content |
|------|---------|
| `models/transformer.json` | Weights after 200 RL rounds (line-abreast) |
| `models/transformer_gaussian.json` | Weights trained on Gaussian ingress |
| `results/eval_*.csv` | 30-round metrics, line-abreast |
| `results/gaussian/eval_*.csv` | 30-round metrics, Gaussian ingress |
| `results/pvalue.json` | Paired Gaussian \(z\) / TOST |
| `data/experiment.sqlite` | Optional local DB (regenerated by `cargo run`, not stored on GitHub) |
| `paper/figures/` | Paper figures |

CSV/SQLite from a completed run are already in the repo, so tables can be checked without retraining.

Single algorithm:

```bash
cargo run --release -- run --rounds 1 --seed 42 --algo nearest_in_range
cargo run --release -- run --rounds 30 --seed 10000 --algo closer_than_friend
```

Exit codes: 0 ok, 1 invariant, 2 config, 3 SQLite. Logs: `RUST_LOG=battlefield_sim=info`.
